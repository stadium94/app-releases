# App Releases

**English** | [Français](#téléchargements)

This repository hosts downloadable installers for the desktop apps. New builds
are published here automatically.

## Downloading a build

Each product has its own branch, holding only that product's latest build —
no history to browse, just the newest installer. Filenames include the
semantic version (e.g. `retail-manager-setup-0.2.5.exe`), so open the branch
folder to see which version is current, then download from there:

| Product | Branch |
|---|---|
| STIHL — Dibidani | [main-stihl-dibidani](../../tree/main-stihl-dibidani) |
| STIHL — Niamakoro | [main-stihl-niamakoro](../../tree/main-stihl-niamakoro) |
| Niamana Dubai | [main-niamana-dubai](../../tree/main-niamana-dubai) |
| MPM Food | [main-mpm-food](../../tree/main-mpm-food) |

# Téléchargements

**Français** | [English](#app-releases)

Ce dépôt héberge les installateurs téléchargeables des applications de bureau.
Les nouvelles versions y sont publiées automatiquement.

## Télécharger une version

Chaque produit a sa propre branche, qui ne contient que la dernière version
de ce produit — pas d'historique à parcourir, juste le dernier installateur.
Les noms de fichiers incluent le numéro de version (ex :
`retail-manager-setup-0.2.5.exe`) — ouvrez le dossier de la branche pour voir
quelle version est actuelle, puis téléchargez-la depuis là :

| Produit | Branche |
|---|---|
| STIHL — Dibidani | [main-stihl-dibidani](../../tree/main-stihl-dibidani) |
| STIHL — Niamakoro | [main-stihl-niamakoro](../../tree/main-stihl-niamakoro) |
| Niamana Dubai | [main-niamana-dubai](../../tree/main-niamana-dubai) |
| MPM Food | [main-mpm-food](../../tree/main-mpm-food) |
