# App Releases

**English** | [Français](#téléchargements)

This repository hosts **downloadable installers only**. It contains no application
source code, no build scripts, and no CI configuration — every release here is
published automatically by a separate, private build pipeline.

## Downloading a build

Go to the **[Releases](../../releases)** page and pick the build you need. Each
release includes a Windows installer (`.msi` and/or `.exe`) as a downloadable asset.

## Which release is which product

Releases are tagged by product and build number:

| Tag prefix | Product |
|---|---|
| `main-stihl-dibidani-*` | STIHL — Dibidani |
| `main-stihl-niamakoro-*` | STIHL — Niamakoro |
| `main-niamana-dubai-*` | Niamana Dubai |
| `main-mpm-food-*` | MPM Food |

The newest release for each product is always at the top of the Releases page,
sorted by publish date.

## About this repository

This account exists solely to distribute finished builds. If you're looking for
the application source code, you're in the wrong place — it isn't here, and it
never will be.

# Téléchargements

**Français** | [English](#app-releases)

Ce dépôt héberge **uniquement des installateurs téléchargeables**. Il ne contient
aucun code source de l'application, aucun script de build et aucune configuration
CI — chaque version publiée ici l'est automatiquement par un pipeline de build
privé distinct.

## Télécharger une version

Rendez-vous sur la page **[Releases](../../releases)** et choisissez la version
souhaitée. Chaque publication inclut un installateur Windows (`.msi` et/ou `.exe`)
en tant que fichier téléchargeable.

## Quelle version correspond à quel produit

Les versions sont identifiées par produit et numéro de build :

| Préfixe du tag | Produit |
|---|---|
| `main-stihl-dibidani-*` | STIHL — Dibidani |
| `main-stihl-niamakoro-*` | STIHL — Niamakoro |
| `main-niamana-dubai-*` | Niamana Dubai |
| `main-mpm-food-*` | MPM Food |

La version la plus récente de chaque produit apparaît toujours en haut de la page
Releases, triée par date de publication.

## À propos de ce dépôt

Ce compte sert uniquement à distribuer les builds finalisés. Si vous cherchez le
code source de l'application, vous êtes au mauvais endroit — il n'est pas ici et
ne le sera jamais.
